# Solar Check — Nigeria

A static Nigeria solar generation estimator covering 36 states + FCT and all 774 LGAs.

## Run
Open `index.html` in a browser or deploy the folder to Netlify, Vercel, GitHub Pages, Cloudflare Pages, etc.

## Data
- Administrative coverage: Open Admin Data Nigeria administrative divisions (37 top-level divisions, 774 LGAs, coordinates), CC BY 4.0.
- Current weather/solar radiation: Open-Meteo.
- Long-term solar climatology: NASA POWER.
- Solar PV methodology context: Global Solar Atlas / Solargis.

## Important accuracy note
The app intentionally does NOT claim 99.9% real-world accuracy. Real output depends on site shading, roof azimuth/tilt, panel temperature, dust, inverter efficiency, wiring, battery losses, clipping, downtime and actual weather. Use a site survey and detailed PV simulation for bankable engineering.
